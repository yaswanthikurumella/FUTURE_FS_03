# ☕ YASHV Café - Local Business Website

## 📌 Project Overview

YASHV Café is a professional café website developed as part of the Future Interns Full Stack Web Development Internship (Task 3: Local Business Website & Live Pitch Project).

The website is designed to help a local café improve its online presence, attract more customers, and simplify table reservations through a user-friendly booking system.

---

## 🚀 Features

* Modern and responsive café website design
* Attractive hero section
* About Us section
* Menu section with images and pricing
* Gallery showcasing café atmosphere and products
* Online table reservation system
* Booking data stored using Local Storage
* Demo Admin Panel for viewing reservations
* Contact & Reservation form
* Mobile-friendly layout
* GitHub Pages deployment

---

## 🛠 Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage API
* GitHub
* GitHub Pages

---

## 💡 Business Benefits

This website helps YASHV Café by:

* Increasing online visibility
* Providing customers with an easy reservation process
* Showcasing menu items visually
* Improving customer engagement
* Creating a professional digital presence
* Supporting future online ordering and business expansion
